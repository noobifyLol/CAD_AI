How to use

Learning database

Use this when a generation does not appear in Supabase or the memory weights are not changing.

Step 1 — Generate FeatureScript

Type a description of your part in the Generate tab. Include shape, dimensions, holes, and any fillets. Click Generate or press Ctrl+Enter. The AI Reasoning box shows exactly what the AI understood before generating code.

Step 2 — Paste into Onshape

In Onshape, open your document and create or open a Feature Studio tab. Select all (Ctrl+A) and paste the generated code.

Step 3 — Insert the feature

Switch to your Part Studio. The feature appears in the toolbar. Click it, select a plane, then click the checkmark.

Multi-image analysis

Use the Images tab to upload several reference images at once — for example, a hand-drawn sketch as Image 1 and a dimension sheet as Image 2. Label each image so the AI knows its role. The AI synthesizes all images together before generating FeatureScript.

Got an error?

Use the Debug tab. Paste your FeatureScript and the error message from Onshape. The AI will explain what went wrong and return a corrected version.

Supported shapes

Box / cube / block — Cylinder / rod / shaft — Flat plate — Polygon (triangle, hex, any N-sided) — Linkage / connecting rod — Mounting plate with holes — L-bracket / angle iron — T-bracket — U-channel — Pipe flange — Hex nut — Washer — Bushing — Stepped shaft — Spur gear (with real tooth profiles)

Gear tips

Say 8:1 gear and the AI generates a 64-tooth driven gear (mates with an 8-tooth pinion). Or say spur gear 32 teeth, 2mm module for explicit control. Specify a bore with 0.5 inch bore. Face width defaults to 8× the module.

Dimension tips

Dimensions default to inches. Say mm and the AI converts automatically. Missing dimensions get sensible mechanical defaults.
